⚡ Турбо-узел (vless-turbo) — максимальная скорость


Тот же сервер, ускоренный: ответ без ожидания записи и 0-RTT early-data (минус один round-trip на подключении). Втыкать так же — «+ → Импорт из буфера»:






Для скорости: фрагментация выключена (сильно режет скорость), Mux выключен, маршрутизация «Глобальный». Путь /?ed=2048 уже вписан — это 0-RTT, не меняй его.







🚀 Правила скорости (важнее сервера)


    

  1. В v2rayNG для узла: Mux = выкл, фрагментация = выкл (у порта 80 они не нужны), DNS = «Удалённый».
    2. 

  2. Русские сайты, банки и маркетплейсы — не пускать через VPN: v2rayNG → Настройки → «Режим VPN» → Все приложения → выбрать только YouTube, Google, Chrome/браузер (магазин приложений). Остальное ходит напрямую и не тормозит.
    3. 

  3. Выбери ближайший узел: «Тест реальной задержки» — кто меньше (<100 мс на Wi-Fi — отлично).
    4. 

  4. Скорость Wi-Fi vs мобильный интернет может отличаться — тестируй в обеих сетях.
    5. 

  5. Если скорость резко упала — переключись на другой узел: все взаимозаменяемые.
    6. 



Замер через туннель: ~115–130 Мбит/с (5 МБ за 0.3–0.7 c) — упор скоростью обычно в канал провайдера и фильтрацию, а не в сервер.







🤖 АВТО-узел (vless-auto) — самолечение + авто-маршрутизация


Главный режим «всё само»: Россия/банки — напрямую (выбирать приложения не нужно), всё зарубежное — через VPN. Самолечение тоже внутри: каждые 15 минут робот проверяет все узлы и сам перекатывает зависший.

🔥 Самолечение (автоматический «врач»)


В репозитории работает воркфлоу vpn-guard: каждые 15 минут проверяет все узлы. Если какой-то перестал отвечать — робот сам удаляет и пересоздаёт его из кода в репо (это лечит известную «залипшую» проблему аккаунта). Если хочешь проверить вручную: вкладка Actions → vpn-guard → Run workflow.







📱 Узел для телефона (vpn-phone) — «встроить в настройки»


Тот же VLESS, но настроенный на постоянную работу: после импорта включи его в настройках телефона как постоянный VPN (см. шаги ниже на странице проверки). Вставляй через «+ → Импорт из буфера»:






На Honor (EMUI): Настройки → Ещё → VPN → при включённом v2rayNG там появится профиль — в его настройках включи «Постоянный VPN» (Always-on) и «Без VPN не подключаться», тогда телефон всегда выходит через этот узел.







Ограничение (важно понимать)


Cloudflare запрещает воркерам ходить на сайты, которые сами работают через Cloudflare (примерно каждая пятая ссылка в интернете). Гугл, YouTube, Instagram, X, Telegram и большинство сервисов — работают.
